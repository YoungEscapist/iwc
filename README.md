# IWC — Infinity Wayland Compositor

Отдельный Wayland-композитор на Rust и wlroots 0.20 с Lua-конфигом. Каждый новый
рабочий стол начинается в master/stack tiling (не колонках); режим переключается отдельно для каждого стола.
В floating окна находятся на бесконечном двумерном холсте. Перемещение камеры не меняет
размеры и мировые координаты окон и не отправляет приложениям поток configure.
Чистая сессия: без панели, обоев, анимаций и фоновых помощников. Оформление DWR не меняется.

| Включить tiling / floating явно | Super+T / Super+Shift+D |
| Перечитать Lua-конфиг | Super+Shift+R |
| Прыжок к окну слева/справа/сверху/снизу | Super + стрелки либо H/L/K/J |
| Перебор окон, включая оставшиеся за экраном | Super+Tab / Super+Shift+Tab; Alt+Tab / Alt+Shift+Tab |
| Центрировать выбранное окно | Super+Home / Super+средняя кнопка |

| Изменить размер окна под курсором | Super+свайп тремя пальцами |

| Центрировать окно в фокусе | Удержание четырьмя пальцами; Super+удержание тремя |
| Прокрутить колонки / перейти по столам в niri | Alt+два пальца горизонтально / вертикально |
| Панорамирование колёсиком | Alt+колесо; Alt+Shift+колесо — горизонтально |

| Масштабирование под курсором во floating | Super+колесо; pinch тремя пальцами; Super+pinch двумя; pinch двумя над пустым холстом; Alt+pinch двумя |
| Полный экран окна под курсором | Alt+pinch тремя пальцами внутрь или наружу |
| Приблизить / отдалить | Super + `+`/`=` / `-` |
| Масштаб 100% | Super+0 |
| Перетаскивать/изменять размер окна | Super+левая/правая кнопка мыши |
| Рабочие столы / перенести окно | Super+1…9 / Super+Shift+1…9 |
| Терминал / приложения | Super+Enter / Super+Space либо Super+S |
| Закрыть окно / выйти из сеанса | Super+Q / Super+Shift+Q |
| Полный экран | F11 / Super+F |

В floating новые обычные окна появляются в центре текущего вида камеры, с учётом
масштаба и выбранного монитора. Диалоги центрируются относительно родителя. Пространственный
выбор, как в Parallax, сначала предпочитает лучшее совпадение с направлением;
при равном угле выбирается ближайшее окно. Если кандидатов нет, фокус сохраняется.

Масштаб холста — от 25% до 300%, точка под курсором при зуме сохраняется.
Мировая геометрия и размеры буферов клиентов не меняются: масштабируется проекция
окон, subsurfaces, попапов и рамок. Панель и fullscreen не масштабируются.
Ввод преобразуется обратно в координаты поверхностей; мышиные move/resize работают
при любом масштабе. Клавиатурное перемещение окон и команды `move-*` удалены.
Курсор при панорамировании остаётся на месте. Свайп и pinch можно отменить;
блокировка экрана и fullscreen блокируют навигацию холста. Режим, камера и масштаб
сохраняются отдельно для каждого стола на каждом выходе. При возврате из tiling
восстанавливается floating-геометрия окон. При показе нескольких меток используется
режим младшей выбранной метки. Пан/зум доступны только в floating.
При первом переходе в floating окна расходятся вокруг центра вида; последующие
переходы восстанавливают их прежние позиции и размеры. Перемещение/resize в tiling
временно выводит окно из раскладки; следующий переход floating → tiling возвращает
его в раскладку. Явные floating-исключения (`toggle-floating`, правила и диалоги)
остаются поверх tiling. Во floating оконные жесты не закрепляют такие исключения.

Режимы и основные жесты сверены с локальным Parallax `9ef5643`:
`src/tiling.rs`, `src/input.rs`, `src/gestures.rs` и действующими defaults
`ЖЕСТЫ_ПО_УМОЛЧАНИЮ` в `src/config.rs` (комментированный образец Lua местами старее).
Прыжок срабатывает один раз после порога 12 пикселей, в сторону движения вида,
то есть противоположно пальцам. Alt+pinch переключает fullscreen один раз при
достижении 0.85 / 1.15, не дожидаясь отпускания. Обычный двухпальцевый скролл над
приложением остаётся приложению. Обзор всех столов и групповой snap Parallax сюда
не перенесены; это не полная реализация Parallax.
При панорамировании мышью или тачпадом курсор становится рукой захвата (`grabbing`),
при завершении/отмене жеста восстанавливается. Координаты ограничены ±8 млн логических пикселей.

## Lua-конфиг

Путь: `$XDG_CONFIG_HOME/iwc/config.lua`, обычно `~/.config/iwc/config.lua`.
Другой файл: `IWC_CONFIG=/path/config.lua iwc`. Без файла действуют настройки ниже.
Образец устанавливается в `share/iwc/config.lua`; изменения применяются через
`Super+Shift+R` или `iwcctl reload`. При ошибке перезагрузки прежний конфиг сохраняется,
при ошибке запуска используются безопасные значения по умолчанию; ошибка идёт в stderr.

```lua
return {
    layout = "master",
    gaps = 16,
    column_width = 1 / 2,
    center_focused = false,
    binds = {
        ["Super+d"] = "layout",
        ["Super+Shift+d"] = "floating",
        ["Super+t"] = "tiling",
        ["Super+Shift+r"] = "reload",
    },
}
```

`layout = "niri"` — горизонтальные прокручиваемые колонки: одно окно в колонке,
высота по рабочей области, ширина как доля доступной ширины (`0.1…1`), автоматическая
прокрутка к выбранному окну без уменьшения остальных окон. Это базовая niri-подобная
раскладка, не полная реализация niri: стеки внутри колонок и перенос колонок не добавлены.
`center_focused = true` всегда центрирует выбранную колонку; иначе прокрутка минимальная.
`layout = "master"` — master/stack tiling по умолчанию. `gaps` — `0…256` пикселей.
Оба варианта остаются tiling: Lua не меняет правило «новый стол → tiling».

`binds` дополняет стандартные бинды, совпадающий chord заменяется. Модификаторы:
`Super`, `Shift`, `Ctrl`, `Alt`; последняя часть — XKB keysym (`Return`, `Left`, `t`).
Действия — команды `iwcctl`: `layout`, `tiling`, `floating`, `reload`, `focus-*`,
`pan-*`, `zoom-*`, `view N`, `tag N`, `terminal`, `launcher`, `center`, `fullscreen`, `close`,
`toggle-floating` (постоянное floating-исключение для выбранного окна).

## Сборка и запуск

```sh
nix-shell --run 'cargo build --release --offline'
./target/release/iwc -s 'foot'
```

В DRM-сеансе запускать из свободного TTY, не поверх работающего композитора.
Для вложенного запуска можно использовать `WLR_BACKENDS=wayland`.
Пакет `package.nix` устанавливает отдельную сессию **IWC**, утилиту
`iwcctl` и образец Lua-конфига. Сессия запускает только `iwc`, без rice/autostart. DWR не заменяется.

Конфигурация: `~/.config/iwc/config.lua`. Внешняя оболочка не запускается.
Сокет и статус: `$XDG_RUNTIME_DIR/iwc-$WAYLAND_DISPLAY.sock` и `.status`.
Анимаций нет, включая открытие/закрытие окон и прыжки камеры. Курсор следует за окном
при перемещении и ресайзе мышью/тачпадом, включая ограничение размера.
Окна перемещаются свободно: прилипания к краям экрана нет, в том числе при зуме
и переносе окна за границы видимой области холста.
Размер configure сверяется с запланированным, а не старым подтверждённым размером:
быстрый возврат режима не оставляет старый размер для следующего focus/hover configure.
Стандартные бинды находятся в `src/config.rs`,
пользовательские — в Lua.

```sh
iwcctl layout
iwcctl tiling
iwcctl floating
iwcctl reload
iwcctl focus-right
iwcctl pan-left
iwcctl zoom-out
iwcctl zoom-reset
iwcctl center
iwcctl view 2
```

Помощник управления не посылает клавиши в чужой сеанс, если IWC не запущен.

## Проверки

```sh
nix-shell --run 'cargo test --offline'
nix-shell --run 'cargo test --offline infinite_canvas_headless -- --ignored --nocapture'
```

Второй тест создаёт собственный runtime-каталог, headless-выход и три настоящих
окна foot. Проверяются размещение, off-screen прыжки, центрирование и hit testing,
неизменность геометрии при пане/зуме, привязка зума к курсору, ввод при разных
масштабах, screencopy, мышь, колесо, отмена жеста, lock/fullscreen,
IPC, режимы столов и независимые камеры, niri/master tiling, восстановление floating
и закрытие клиентов. Текущий графический сеанс не затрагивается. Unit-тест Lua исполняет
настоящий Lua-код и проверяет настройки, бинды и отклонение ошибочной конфигурации.

## Происхождение и границы

Wayland/DRM/Xwayland/protocol plumbing взят из локального DWR, HEAD `5f44e4d`
с текущими рабочими изменениями на 21.11.2026. Исходники DWR не изменяются.
Эталон навигации — локальный `/root/src/parallax-wm`, HEAD `9ef5643`,
репозиторий `YoungEscapist/parallax-wm`: `src/tiling.rs` (`focus_direction`,
`snap_camera_to_window`), `src/state.rs` (`pan_camera_by`), `src/canvas.rs`.
Новая логика IWC находится в `src/infinity.rs`.

Это масштабируемый холст и пространственная навигация, не полный клон Parallax:
отдельный режим overview, групповой snap, 3D и его эффекты здесь не реализованы.
Сохранены исходные GPL-3.0 лицензии DWR/dwl и зависимости.
